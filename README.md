# QR Code Generator 🌐

A lightweight, responsive web application for generating and downloading high-quality QR codes instantly.

## Features ✨

- 🚀 Instant QR code generation for URLs, text, or contact information
- 🖼️ High-resolution (500x500px) QR codes
- ⬇️ One-click PNG download functionality
- 📱 Fully responsive design (works on all devices)
- 🔌 No backend required - pure frontend solution

## Tech Stack 💻

- **Frontend**: HTML5, CSS3, JavaScript
- **QR Library**: [QRCode.js](https://github.com/davidshimjs/qrcodejs) (Lightweight ~10KB)

## Usage 🛠️

1. Enter any text or URL in the input field
2. Click "Generate QR Code"
3. Download the generated QR code as PNG
